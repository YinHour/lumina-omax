# 放大风险与验证 Gate

## 方法目标

把实验室结果转化为分阶段的放大决策，防止在混合、传热、传质、剪切、原料波动或设备尺度改变后失效。

## 工作流程

1. 定义目标产品和关键质量属性，包括组成、活性含量、粒径或分子量分布、黏度、稳定性和应用性能。
2. 绘制实验室过程：原料加入顺序、局部浓度、混合时间、剪切、温度、传热、停留、过滤、储存和包装。
3. 识别尺度敏感参数：
   - 功率密度、叶尖速度、雷诺数和混合时间；
   - 加料点、加料速率和局部 pH 或浓度；
   - 升降温速率、热点和冷却能力；
   - 气液、固液传质和脱泡；
   - 停留时间分布、死区、壁面吸附和清洗残留。
4. 建立失效模式表，记录原因、影响、可检测信号、预防控制和应急处置。风险评分与证据水平分别记录。
5. 设置阶段 Gate：
   - 实验室重复性 Gate；
   - 工程模拟或放大模型 Gate；
   - 小试到中试 Gate；
   - 中试到现场试用 Gate；
   - 稳定生产与变更控制 Gate。
6. 每个 Gate 给出必须提交的数据包、关键质量属性范围、过程参数范围、批次数、偏差处理和放行责任。
7. 规定失败后的回退路径、调查范围和再次进入条件，避免只给“继续优化”的模糊结论。

## 输出结构

- 产品目标与关键质量属性
- 实验室过程和尺度变化
- 关键过程参数与风险
- 分阶段验证矩阵
- Gate 的进入、通过、暂停和回退标准
- 现场监测与变更控制
- 剩余风险和数据缺口

## 质量检查

- 放大依据不是仅按体积线性倍增。
- 原料批次与供应商变化纳入验证。
- 每个 Gate 有可判定的数据和责任边界。
- 失败有明确的隔离与回退路线。
