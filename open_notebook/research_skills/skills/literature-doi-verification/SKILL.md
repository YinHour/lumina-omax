# 文献检索与 DOI 核验

## 方法目标

把研究问题转换为可复现的检索过程，并确认“文献记录”和“DOI 所指对象”一致。数据库命中只是线索，不等于已阅读全文或验证了论文结论。

## 工作流程

1. 用一句话界定研究对象、干预或配方、比较条件、响应指标和适用边界。缺少的条件列为待确认项。
2. 建立概念组：核心术语、同义词、缩写、旧名称、材料牌号、化学标识和排除词。油田化学问题还应列出水泥体系、盐水组成、温压和养护条件。
3. 为每个数据库给出实际使用的检索式、筛选日期和过滤条件。先宽检索发现术语，再用关键字段收窄。
4. 按 DOI 规范化值去重；无 DOI 时用题名、第一作者、年份和期刊组合去重。预印本与正式发表版本保留关联，但不能当作两个独立证据。
5. 至少用两个独立元数据来源核对 DOI。比较题名、作者、期刊或会议、年份、卷期页和文献类型；记录不一致字段。
6. DOI 解析成功不代表元数据正确；元数据一致也不代表全文可得。分别报告解析状态、元数据一致性和全文可得性。
7. 对纳入记录保留精确证据 ID。只有工具返回的记录可进入证据表，不补造 DOI 或缺失字段。

## 输出结构

- 研究问题与边界
- 数据库、检索式、日期和过滤条件
- 纳入与排除标准
- 去重规则与版本关联
- DOI 核验表：候选记录、核对来源、一致字段、冲突字段、状态
- 证据缺口：未核验全文、缺 DOI、元数据冲突或覆盖不足
- 下一轮检索建议

## 质量检查

- 检索式能由他人复现。
- 题名相似但研究条件不同的记录未被错误合并。
- 预印本、勘误、撤稿和正式版本已标记。
- 所有 DOI 和外部记录 ID 均来自真实工具结果。
