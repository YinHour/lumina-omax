# 内容转换 — 批量处理你的来源

Transformations（转换）用同一模板对多个来源施加相同分析。不必重复问同样的问题，定义模板后一键运行。

---

## 何时使用

| 用 Transformations | 用 Chat |
|--------------------|---------|
| 多条来源同一种分析 | 一次性问题 |
| 需要一致的输出格式 | 探索性对话 |
| 批量处理 | 需要追问 |
| 创建结构化笔记 | 上下文频繁变化 |

**示例**：你有 10 篇论文，想获取每篇的摘要——用 Transformations 一次操作完成。

---

## 内置模板

所有模板已本地化为中文：

### 摘要
提取：要点、主要论点、结论。输出：200-300 字概述。

### 关键概念
提取：主要思想和术语。输出：概念列表及解释。

### 方法论
提取：研究方法、途径、数据。输出：研究如何进行的。

### 要点
提取：可执行的洞察和建议。输出：你该用这些信息做什么。

### 问题
提取：来源引发的问题。输出：开放问题、空白点、后续研究方向。

> **注意**：所有内置模板已中文化，AI 处理提示词也包含简体中文输出指令。自定义模板可使用任意语言。

---

## 创建自定义模板

```
示例模板：
"分析这篇学术论文，提取：
1. 研究问题
2. 方法论
3. 主要发现（编号列表）
4. 局限性
5. 后续研究建议
请引用页码。"
```

> **模板管理权限**：内置转换模板作为系统级配置，**编辑、删除模板**和**修改默认 Prompt** 仅管理员（`role=admin`）可操作。前端编辑/删除按钮仅对管理员渲染，后端对应端点有 `require_admin` 依赖兜底。Playground 测试功能保持全员可用。

## 应用转换

### 单条来源
来源面板 → 来源菜单(⋮) → "转换" → 选模板 → "应用"

### 批量来源
Transformations 页面 → 选模板 → 勾选多个来源 → "应用到已选"

---

## 输出管理

- 每条来源生成一条笔记
- 笔记出现在笔记面板中
- 命名格式："[模板名] - [来源名]"
- 可编辑、精炼输出

---

## 最佳实践

1. **先测试** — 在一条来源上测试模板，确认效果后再批量
2. **指定格式** — 明确要求标题、列表、编号
3. **设定长度** — 防止输出过长或过短
4. **要求引用** — 让结果可验证
