# 高效搜索 — 找到你需要的内容

搜索是你进入研究的入口。本指南涵盖两种搜索模式和 Ask 自动搜索功能。

---

## 两种搜索模式

### 文本搜索（关键词匹配）

**工作原理**：你搜词语，系统找包含这些词的片段

**速度**：即时，非常快

**何时用**：
- 记得精确词语或短语
- 找特定术语
- 需要精确引用

### 向量搜索（语义/概念匹配）

**工作原理**：你的搜索转换为向量，找语义最相似的片段

**速度**：稍慢（1-2 秒）

**何时用**：
- 探索概念
- 不知道精确词语
- 找语义相关的内容

---

## 决策：用哪种？

```
问题："我记得精确词语吗？"

→ 是 → 用文本搜索
→ 否 → 用向量搜索
→ 不确定 → 先用文本搜索（更快）
```

---

## Ask 功能（自动搜索）

Ask 不同于简单搜索。它自动搜索、综合分析并回答，全程实时流式输出。

### 工作流程

```
阶段 1：理解问题 → AI 分析你的问题
阶段 2：搜索策略 → AI 确定搜索角度（流式显示思考过程）
阶段 3：并行搜索 → 向量搜索 + 知识图谱双重检索
阶段 4：综合回答 → 逐字流式输出（打字机效果）
```

Ask 将**向量搜索**（语义相似度）与**知识图谱**（图结构实体关系）并行组合——实现 Hybrid RAG 架构。

可点击停止按钮中断生成，已生成内容会保留。

---

## 何时用 Ask vs 简单搜索

| 任务 | 用 | 原因 |
|------|-----|------|
| "找到关于 X 的引用" | **文本搜索** | 需要精确词语 |
| "比较 A 和 B" | **Ask** | 综合回答 |
| "探索 X 概念" | **向量搜索** | 语义发现 |
| "全局视角" | **Ask** | 跨来源综合分析 |

---

## 搜索技巧

### 文本搜索
1. 精确短语加引号："注意力机制"
2. 使用技术术语

### 向量搜索
1. 用自然语言提问
2. 描述你正在找什么
3. 从宽泛开始，逐步收窄
