# 引用与验证 — 验证 AI 断言

引用让你能验证 AI 的回答是否准确。Lumiton·Omax 使用内联引用格式：

```
AI 回复示例：
"该论文报告了 95% 的准确率 [1](https://...)"
"如研究所述 [2](https://...)"

## 参考文献
[1] 论文标题，第 12 页
[2] 另一篇论文，第 3.2 节
```

- `[1](URL)` — 指向具体来源的内联引用
- `## 参考文献` — 回复末尾的文献列表
- 点击任意编号引用可直接跳转到源材料

---

## 双轨引用与兜底

Lumiton·Omax 的引用体系区分**本地来源**与**网络引用**（联网搜索结果）：

- **本地/网络引用隔离** — 前端自动探测网络引用的编号上限，本地来源与网络结果分开编号，便于区分证据来源
- **前端后处理兜底** — 当 AI 输出的引用序号有缺失时，前端用正则补全，防御跳号、不带链接、双结尾等格式问题
- **Few-Shot 防御** — 系统提示词含负面样本，降低 AI 产出格式不规范引用的概率

> 联网搜索结果若启用，会在本地来源编号之后单独编号，并标注为网络来源。

---

## 验证流程

1. 从 Chat 获取回答
2. 检查引用（哪个来源？哪一页？）
3. 点击引用链接
4. 查看来源中的实际文本
5. 它真的说了 AI 声称的内容吗？

**是** → 可以信任这个答案
**否** → AI 产生了幻觉，请求更正

---

## 请求更好的引用

如果回复没有引用，追问：
- "请为这个断言引用页码"
- "告诉我你在哪里找到这个信息"

AI 将会查找引用并提供页码。
