# 引用与验证 — 验证 AI 断言

引用让你能验证 AI 的回答是否准确。Lumiton·Omax 使用内联引用格式：

```
AI 回复示例：
"该论文报告了 95% 的准确率 [1](https://...)"
"如研究所述 [2](https://...)"

## 参考文献
[1] 论文标题，第 12 页
[2] 另一篇论文，第 3.2 节
```

- `[1](URL)` — 指向具体来源的内联引用
- `## 参考文献` — 回复末尾的文献列表
- 点击任意编号引用可直接跳转到源材料

---

## 验证流程

1. 从 Chat 获取回答
2. 检查引用（哪个来源？哪一页？）
3. 点击引用链接
4. 查看来源中的实际文本
5. 它真的说了 AI 声称的内容吗？

**是** → 可以信任这个答案
**否** → AI 产生了幻觉，请求更正

---

## 请求更好的引用

如果回复没有引用，追问：
- "请为这个断言引用页码"
- "告诉我你在哪里找到这个信息"

AI 将会查找引用并提供页码。
