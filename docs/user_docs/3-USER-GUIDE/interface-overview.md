# 界面总览 — 熟悉环境

Lumiton·Omax 采用三栏布局，支持多用户认证与温暖研究风格的视觉设计系统。

---

## 登录与注册

### 首次访问

打开应用后看到 **Landing Page**（登录页）：

- **左侧** — 产品介绍、核心 R&D 方法论、关键指标（+40% 实验复用率 / -30% 现场失效风险 / 1/2 试错周期）
- **右侧** — 登录 / 注册表单

### 登录页大屏适配

登录页针对 2K/5K 高分辨率屏幕做了响应式优化：

- 引入 `3xl` 断点（1920px），在 1080p 紧凑、5K 舒展
- 标题、正文、卡片、Logo、输入框均按 `lg:` / `3xl:` 三级渐进式缩放
- 移动端新增品牌头部（Logo + 渐变品牌名），解决小屏仅显示裸表单无品牌标识的问题
- 支持亮色/暗色双主题

### 注册新账号

1. 点击 **Register** 标签
2. 填写：用户名、显示名称、密码（≥6 位）
3. 点击注册
4. 账号状态为 **pending**（等待审批）
5. 管理员审批后方可登录

### 登录

1. 输入用户名和密码 → 登录
2. 管理员可使用部署密码（`OPEN_NOTEBOOK_PASSWORD`）直接以超级管理员身份登录

### 温暖研究设计系统

全站采用「温暖研究」视觉风格：

- **主色**：靛蓝（Indigo）
- **辅助提示色**：琥珀（Amber），仅用于 insight/attention，不作为普通按钮色泛用
- **字体**：现代无衬线系统字体栈
- **配色**：OKLCH 语义色，统一走设计 token
- **动效**：克制柔和，支持 reduced motion
- **卡片**：`interactive` 等语义变体替代旧的 hover scaling

## 侧边栏

侧边栏是主要的导航入口：

### 品牌标识

- Logo 图片 + 品牌文字 `Lumiton·Omax|知涌`（品牌名为硬编码，非 i18n key，因产品名不随语言变化）

### 底部功能区

- **主题 / 语言切换器** — 各占 `flex-1` 平分一行宽度
- **用户信息区** — 首字母头像圆圈 + 显示名称 + @用户名，点击跳转 `/profile`
- **登出按钮**

### 管理员菜单权限控制

- 非管理员用户仅可见「转换」和「帮助」两项
- 「模型」「设置」「高级」自动隐藏（标记 `adminOnly: true`）
- 后端路由已有权限中间件兜底，前端同步隐藏避免困惑

### 最近笔记本

- 侧边栏「笔记本」菜单下展示**最近打开的笔记本**
- 长标题截断，通过 Radix Tooltip 和原生 `title` 属性 hover 查看全名

### 滚动与移动端

- `<nav>` 区域 `overflow-y-auto min-h-0`，底部功能区固定在可视区
- 低于 768px 显示移动菜单触发器，移动抽屉使用 Radix Dialog 支持 Escape 关闭和焦点恢复
- 当前路由使用最长匹配（`/settings/api-keys` 不会误标 `/settings`）

## Sources 全局页

导航栏 → Sources：以表格列出所有笔记本的所有来源，含**上传人**列追踪数据来源。

- 搜索框（回车触发服务端搜索）
- 分页显示「第 X/Y 页，共 Z 条」
- 搜索无结果时区分「暂无来源」和「搜索无匹配」
- 来源标题增加 Tooltip 悬停浮窗

---

## 笔记本首页

笔记本列表页支持多种筛选与组织：

- **名称搜索** — 回车触发
- **活动 / 聚合 / 归档分组**
- **「只看我的」筛选** — 默认关闭，打开后基于当前登录用户 `id` 与笔记本 `created_by` 比较，只显示自己创建的笔记本
- 带密码的笔记本显示**锁定/密码标识**
- 创建者操作（三点菜单）仅创建者可见

---

## 设置页

### 用户审批面板（仅管理员）

管理员在设置页底部看到：

- 按 pending/active/rejected 筛选用户列表
- **批准**注册（用户变为 active）
- **拒绝**申请
- **禁用**活跃账号
- **切换角色**：User ↔ Admin（点击角色标签）
- **重置密码**（安全弹窗，需二次确认输入）

### 文件管理区

- **添加来源数量上限** — 数字输入，默认 50，范围 1-200（详见 [添加来源](adding-sources.md#来源数量上限)）

---

## 个人资料页 `/profile`

点击侧边栏用户信息区进入个人资料页：

- **首字母头像 + 角色标签**（管理员 ShieldAlert / 用户 Shield）
- **状态标签**（已激活 CheckCircle / 等待审批 Clock / 已拒绝 XCircle）
- **显示名称编辑** — 输入框 + 保存按钮，调用 `PUT /auth/me`
- **修改密码** — 当前密码验证 + 新密码确认，调用 `PUT /auth/me/password`

## 常用操作

| 操作 | 步骤 |
|------|------|
| 创建笔记本 | 笔记本页 → [+ 新笔记本] |
| 添加来源 | 笔记本内 → [+ 添加来源] → 选类型 → 上传/粘贴 |
| 发送消息 | Chat 面板 → 输入 → Enter |
| 保存 AI 回复 | 好回复 → [保存为笔记] |
| 切换上下文级别 | 点击来源 → 选 完整/摘要/不参考 |
| 管理笔记本密码 | 笔记本卡片「...」菜单 → 密码（设/改/撤销） |
