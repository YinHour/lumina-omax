# 界面总览 — 熟悉环境

Lumiton·Omax 采用三栏布局，支持多用户认证。

## 登录与注册

### 首次访问

打开应用后看到 **Landing Page**：
- **左侧** — 产品介绍、核心 R&D 方法论、关键指标
- **右侧** — 登录 / 注册表单

### 注册新账号
1. 点击 **Register** 标签
2. 填写：用户名、显示名称、密码（≥6 位）
3. 点击注册
4. 账号状态为 **pending**（等待审批）
5. 管理员审批后方可登录

### 登录
1. 输入用户名和密码 → 登录
2. 管理员可使用部署密码直接登录

## Sources 全局页

导航栏 → Sources：以表格列出所有笔记本的所有来源，含**上传人**列追踪数据来源。

---

## 设置页

### 用户审批面板（仅管理员）

管理员在设置页底部看到：

- 按 pending/active/rejected 筛选用户列表
- **批准**注册（用户变为 active）
- **拒绝**申请
- **禁用**活跃账号
- **切换角色**：User ↔ Admin（点击角色标签）
- **重置密码**（安全弹窗，需二次确认输入）

## 常用操作

| 操作 | 步骤 |
|------|------|
| 创建笔记本 | 笔记本页 → [+ 新笔记本] |
| 添加来源 | 笔记本内 → [+ 添加来源] → 选类型 → 上传/粘贴 |
| 发送消息 | Chat 面板 → 输入 → Enter |
| 保存 AI 回复 | 好回复 → [保存为笔记] |
| 切换上下文级别 | 点击来源 → 选 Full/Summary/Excluded |

## 键盘快捷键

| 键 | 动作 |
|-----|------|
| Enter | 发送消息 |
| Shift+Enter | 换行 |
| Escape | 关闭对话框 |
