# 笔记管理 — 捕获和组织洞察

笔记是你处理后的知识。本指南涵盖如何创建、组织和使用它们。

---

## 什么是笔记？

笔记是你的**研究输出**——从分析来源中捕获的洞察。

- **手动** — 你自己写的
- **AI 生成** — 来自 Chat 回复、Ask 结果或 Transformations
- **混合** — AI 洞察 + 你的编辑补充

与来源不同（不可变），笔记可编辑——你修改、精炼和整理它们。

---

## 快速入门：创建笔记

### 方法 1：手动笔记
笔记本 → Notes 区域 → "创建新笔记" → 起标题 → 写内容（支持 Markdown）→ 保存

### 方法 2：从 Chat 保存
Chat 中得到好回复 → 点击"保存为笔记" → 起标题 → 保存

### 方法 3：通过 Transformation
Transformations → 选模板 → "应用到来源" → 选来源 → 等待处理 → 自动生成笔记

### 方法 4：从 Ask 保存
Ask 答案结果区 → 点击「保存为笔记」→ 起标题 → 保存
也可点击「复制」复制答案，或从浏览器 Ask 历史恢复后再保存（见 [搜索指南 — Ask 历史](search.md#ask-历史)）。

## 组织笔记

### 命名建议
- **日期法**：`2026-01-03 - 来源 X 的关键点`
- **主题法**：`AI 安全 - 对齐方法`
- **类型法**：`摘要：关于 X 的论文`
- **最佳**：组合使用 `[日期] [来源] - [主题] - [类型]`

### 使用标签
- `primary-research`（首要研究）
- `background`（背景材料）
- `methodology`（方法论）
- `insights`（原创思考）
- `questions`（待解决问题）

### 编辑 AI 笔记
AI 笔记 → 点击 → "编辑" → 精炼内容 → 添加你自己的思考 → 保存

---

## 最佳实践

1. **写清楚** — 未来的你会感谢现在的你
2. **加标签** — 创建时立即标记，别拖延
3. **链接来源** — 始终关联来源以便后续验证
4. **定期回顾** — 随理解加深重构笔记
