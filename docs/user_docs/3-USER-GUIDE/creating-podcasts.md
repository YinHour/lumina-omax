# 创建播客 — 将研究转为音频

将你的研究转化为多角色音频对话，供随时收听。

---

## 快速开始

1. 进入笔记本 → 点击 **Podcasts** 标签
2. 选择 **Episode Profile**（话题、长度、语调、格式等）
3. 配置 **Speakers**（主持人、嘉宾及其语音模型）
4. 勾选要包含的来源和笔记
5. 点击 **Generate Podcast**
6. 等待生成完成 → 下载音频

---

## Episode Profile（剧集配置）

定义播客的风格和结构：
- **Topic** — 讨论的主题
- **Length** — 简短/中等/长
- **Tone** — 正式/对话式/教育性
- **Audience** — 目标听众水平

---

## 扬声器配置

可配置多个说话人：
- **Host（主持人）** — 引导讨论，提出问题
- **Guest（嘉宾）** — 回答、深入讨论
- 每个说话人可绑定不同的 TTS 语音模型

---

## 包含内容

选择播客中要讨论的材料：
- 勾选要包含的来源（PDF、文章等）
- 勾选相关笔记
- 系统自动从选定内容生成对话脚本

---

## 常见问题

**"播客生成失败"**
- 确保至少选了 1-2 条来源
- 检查 TTS 提供商的配额
- 等待 30 秒重试
- 尝试切换不同的 TTS 提供商

**"音频质量差"**
- 尝试不同的 TTS 提供商
- 检查语音模型设置
- ElevenLabs 通常音质最好

**"部分语音静音"**
- TTS 合成失败会回退静音音频，不阻塞整个播客生成
- 检查对应说话人的 TTS 提供商配额与凭证
- 切换该说话人的语音模型后重新生成
