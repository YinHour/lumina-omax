# 高效聊天 — 与你的研究对话

Chat 是你探索式提问和来回对话的主要工具。

---

## 快速开始

1. 进入笔记本 → 点击 Chat
2. 选择要包含的来源（上下文）
3. 输入问题 → 发送
4. 阅读回复
5. 追问（上下文保持不变）

---

## 上下文管理

上下文控制 **AI 能看到什么**——这是你最重要的控制。

### 三个级别

**完整内容**
- AI 看到：完整来源文本
- 成本：100% token
- 适用：详细分析、精确引用

**仅摘要**
- AI 看到：AI 生成的摘要（非全文）
- 成本：~10-20%
- 适用：背景材料、参考上下文

**不在上下文中**
- AI 看到：无
- 成本：0
- 适用：机密、不相关、已归档

### 设置方式
Chat → 选择来源 → 勾选/取消 + 选级别 → 保存

---

## 流式输出与停止生成

Chat 响应以**实时流式**（SSE）输出，逐字显示——打字机效果：

- **边写边读** — 无需等待全文
- **停止生成** — 流式中点击红色 Stop 按钮取消
- **保留已生成内容** — 取消不丢失已有文本

---

## 联网搜索（Tavily）

Chat 面板中开启**联网搜索**，让 AI 搜索互联网获取最新信息：

1. 切换 Chat 面板顶部的开关
2. 开启后 AI 可超越上传来源检索实时网页结果
3. 网页结果与本地来源分开引用

需在 Settings → Web Search 配置 Tavily API 密钥。

---

## 引用格式

Lumiton·Omax 使用内联引用 `[1](URL)` + 末尾 `## 参考文献` 格式。点击编号引用可直接跳转到源材料。

---

## 何时用 Chat vs Ask

| 用 Chat | 用 Ask |
|---------|--------|
| 多轮对话探索 | 一次性综合答案 |
| 手动选择来源 | 自动搜索 |
| 调整上下文 | 跨多来源 |
