# AI 与聊天问题

---

## 聊天不工作 / 模型不可用

**解决**：Settings → API Keys → 检查凭证 → 测试连接 → 重新发现和注册模型

---

## API 密钥无效

1. Settings → API Keys → 测试连接
2. 失败 → 去提供商网站获取新密钥
3. 删除旧凭证 → 创建新凭证 → 测试 → 发现模型

---

## 聊天回复差

- 检查上下文：确认相关来源在"完整内容"模式
- 问更好的问题：具体 > 泛泛
- 换更强模型：gpt-4o 或 claude-sonnet
- 要求引用："带页码引用回答"

---

## 聊天太慢

- 换更快模型：Groq、gpt-4o-mini
- 减少上下文来源
- 增加超时：`API_CLIENT_TIMEOUT=600`

---

## 超出速率限制

- 等 1-2 分钟重试
- 换更小/更便宜的模型
- 降低并发操作
- 用 Ollama 本地模型（无限制）

---

## AI 幻觉（编造事实）

- 检查引用：点击引用链接验证
- 确保来源在上下文中
- 要求引用："带引用回答"
- 换更强模型

---

## API 成本过高

- 换便宜模型：gpt-4o → gpt-4o-mini（10x 便宜）
- 减少上下文："仅摘要"模式
- 换 Ollama 本地运行（免费）
