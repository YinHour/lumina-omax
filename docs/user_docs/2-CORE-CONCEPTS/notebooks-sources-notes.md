# 笔记本、来源和笔记 — 容器模型

Lumiton·Omax 用三层关联结构组织研究。理解这一层级关系是高效使用系统的关键。

## 三层结构

```
┌─────────────────────────────────────┐
│         笔记本（容器）               │
│     "AI 安全研究 2026"              │
├─────────────────────────────────────┤
│  来源（原材料）                      │
│  ├─ 安全论文.pdf                     │
│  ├─ 对齐视频.mp4                     │
│  └─ 提示注入文章.html                │
│  笔记（处理后的见解）                 │
│  ├─ AI 摘要（自动生成）               │
│  ├─ 关键概念（转换提取）              │
│  ├─ 我的研究笔记（手动）              │
│  └─ 聊天洞察（来自对话）              │
└─────────────────────────────────────┘
```

---

## 1. 笔记本 — 研究容器

### 什么是笔记本？

笔记本是一个研究项目或主题的**限定容器**。它就是你研究的工作空间。

可以把它想成一个物理笔记本：里面的内容围绕同一主题，共享同一上下文，服务于同一目标。

### 里面有什么？

- **一段描述** — "这个笔记本收集关于 X 主题的研究"
- **来源** — 你添加的原材料
- **笔记** — 你的见解和输出
- **对话历史** — 你的聊天记录和问题

### 为什么这很重要

**隔离性**：每个笔记本完全独立。笔记本 A 中的来源绝不会出现在笔记本 B 中。这让你可以：
- 将不同研究主题完全隔离
- 跨笔记本复用来源名称而不冲突
- 控制每个研究的 AI 上下文范围

**共享上下文**：笔记本中的所有来源和笔记继承笔记本的上下文设定。

**并行项目**：你可以同时运行 10 个笔记本，各为独立的研究环境。

### 聚合笔记本（Aggregate Notebook）

聚合笔记本是一种特殊的笔记本，通过**动态视图关联**把多个笔记本的内容合并到一个视图中：

- 基于 SurrealDB 动态边结构，关联而非物理拷贝
- 毫秒级实时同步——源笔记本更新，聚合视图立即反映
- 独立黑名单：`hidden_sources` / `hidden_notes` 可对聚合视图单独隐藏某些来源/笔记
- 前端：聚合入口、多选弹窗、颜色标签 + 自动聚类、Badge 来源信息卡片
- 合并前逐个校验目标笔记本密码（若加密）

> **用途**：跨多个项目做综合分析、全局检索、汇报汇总，而不破坏各源笔记本的独立性。

### 笔记本密码保护

笔记本可设置密码保护：

- **创建时设密码** — 在新建笔记本弹窗中设置
- **全生命周期管理** — 创建者可随时设密码 / 改密码 / 撤销密码（详见 [界面总览 — 个人资料](../3-USER-GUIDE/interface-overview.md)）
- **加密笔记本** — 全屏密码输入，每次访问必须重新验证
- **管理员密码** — `NEXT_PUBLIC_MASTER_NOTEBOOK_PASSWORD` 可绕过单笔记本密码（超级管理员）
- 创建人展示 + 锁定图标

### 创建者权限

- 笔记本的**三点菜单**（密码、归档、删除）仅**创建者**可见
- 密码管理、归档、更新、删除均要求当前用户为创建者
- 历史笔记本（无 `created_by`）不自动认领——缺少可靠创建者字段时不允许任意用户越权操作
- 创建者名称后端自动取当前用户 `display_name`，无需手动填写

### 来源数量上限

每个笔记本的来源总数有上限，默认 50，管理员可在设置页调整（1-200）。详见 [添加来源 — 来源数量上限](../3-USER-GUIDE/adding-sources.md#来源数量上限)。

## 2. 来源 — 原材料

### 什么是来源？

来源是你导入的**单个输入材料**——原材料。来源不改变，只被处理和索引。

### 可以是什么？

- **PDF** — 研究论文、报告、文档
- **网页链接** — 文章、博客、网页
- **音频文件** — 播客、访谈、讲座
- **视频文件** — 教程、演示、录制
- **纯文本** — 笔记、转录、段落
- **独立图片** — PNG、JPG、TIFF 等（走 Vision 描述链路）

### 添加来源后发生了什么？

```
1. 提取 → 文件/URL → 提取文本和元数据
2. 分块 → 长文本 → 拆分为可搜索的片段
3. 向量化 → 每个片段 → 生成语义向量
4. 存储 → 片段 + 向量 → 存入数据库
```

### 关键属性

**不可变**：一旦添加，来源不再改变。如需新版本，作为新来源添加。

**已索引**：来源自动建立文本和语义搜索索引。

**限定范围**：一个来源可被多个笔记本引用，但所有权属于创建它的笔记本。

**可引用**：其他来源和笔记可以通过引用来引用该来源。

### 删除来源三规则

删除来源的行为按所有权与引用情况区分：

| 场景 | 操作 | 说明 |
|------|------|------|
| 自己创建 + 未被其他笔记本引用 | 直接删除 | 简单确认，无需密码 |
| 别人的源 | 仅移除 | 解除与当前笔记本的关联，不触发物理删除 |
| 自己创建 + 被多笔记本引用 | 需管理员密码 | 校验 `X-Admin-Password`，删除后清理悬空引用 |

详见 [添加来源 — 删除来源三规则](../3-USER-GUIDE/adding-sources.md#删除来源三规则)。

## 3. 笔记 — 处理后的见解

### 什么是笔记？

笔记是**处理后的输出**——你或 AI 基于来源创建的成果。笔记是你研究工作的"成果"。

### 笔记类型

**手动笔记**：你自己撰写的原创思考，记录：
- 从来源学到的东西
- 你的分析和解读
- 下一步行动和问题

**AI 生成笔记**：通过 AI 处理来源创建：
- **Transformations（转换）** — 结构化提取（要点、关键概念、方法论）
- **Chat 回复** — 从对话中保存的答案
- **Ask 结果** — 保存到笔记本的综合答案

### 为什么笔记重要

**知识积累**：笔记构成你真正的知识库，是你从研究中带走的东西。

**可搜索**：笔记与来源一起可被搜索。

**可引用**：笔记可以引用来源，形成洞察来源的溯源链。

---

## 关键设计决策

1. **一个来源对应一个笔记本所有权** — 边界清晰，项目隔离；但可被其他笔记本引用
2. **来源不可变，笔记可编辑** — 来源是证据，不能改动；笔记是思考，可以演进
3. **显式上下文控制** — 你决定哪些来源进入每次交互的上下文
4. **聚合而非拷贝** — 聚合笔记本用动态视图关联，保持源数据单一来源
5. **创建者权限** — 笔记本管理操作限于创建者，避免越权

---

## 总结

| 概念 | 用途 | 生命周期 | 范围 |
|------|------|----------|------|
| **笔记本** | 容器 + 上下文 | 创建后配置 | 其下所有来源 + 笔记 |
| **来源** | 原材料 | 添加→处理→存储 | 一个笔记本所有，可被多笔记本引用 |
| **笔记** | 处理后输出 | 创建/捕获→编辑→分享 | 一个笔记本 |
