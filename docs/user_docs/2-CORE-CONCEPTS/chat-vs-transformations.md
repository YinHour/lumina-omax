# Chat vs Ask vs Transformations — 什么场景用什么工具

Lumiton·Omax 提供不同的研究交互方式。理解何时用哪个是高效使用的关键。

---

## 三种交互模式

### 1. Chat（聊天）— 手动上下文的对话探索

**流程**：
1. 你选择要在上下文中包含的来源
2. 提问
3. AI 只基于这些来源回答
4. 追问（上下文保持不变）

**适用**：探索特定主题、多轮对话、你知道哪些来源重要

---

### 2. Ask（提问）— 自动综合搜索

**流程**：
1. 你提出一个复杂问题
2. 系统自动分析并搜索你的来源
3. 检索相关片段
4. 综合为一个详细答案

**适用**：综合一次性问题、多来源对比、让系统决定什么相关

---

### 3. Transformations（转换）— 模板化处理

**流程**：
1. 你定义一个模板（或选择预设）
2. 逐条应用到每条来源
3. 每条来源 → 结构化笔记

**适用**：从每条来源提取相同信息、创建格式一致的结构化摘要、建立分类知识库

---

## 决策树

```
你想做什么？

├── "我想就这个主题进行对话"
│   └── 用 Chat — 多轮对话，你控制上下文

├── "我需要一次性综合答案"
│   └── 用 Ask — 自动搜索，综合回答

├── "我想从每条来源提取相同信息"
│   └── 用 Transformations — 模板化逐条处理

└── "我只想阅读和搜索"
    └── 直接搜索（文本或向量）
```

---

## 对比

| 维度 | Chat | Ask | Transformations |
|------|------|-----|-----------------|
| **用途** | 对话探索 | 综合问答 | 模板化提取 |
| **问题数** | 多个（对话式） | 一个 | 每条来源一个模板 |
| **上下文控制** | 手动 | 自动 | 逐条来源 |
| **输出** | 自然对话 | 自然答案 | 结构化笔记 |
| **速度** | 快 | 较长 | 逐条处理 |

---

## 模式组合

```
Transformations → Chat
  1. 用转换提取结构化数据
  2. 用 Chat 讨论结果

Ask → Transformations
  1. 用 Ask 理解关键信息
  2. 用 Transformations 逐条提取

Chat → 保存为笔记
  1. 对话探索
  2. 保存好的回复为笔记
```

---

## 总结

| 场景 | 用 | 原因 |
|------|-----|------|
| 想探索话题 + 追问 | Chat | 对话式，你控制上下文 |
| 一个复杂问题需要综合答案 | Ask | 自动搜索，综合回答 |
| 每条来源统一格式提取 | Transformations | 模板复用 |
| 对比两个特定来源 | Chat | 只选两个，深入讨论 |
| 了解全局 | Ask | 跨来源自动搜索 |

核心洞察：**不同问题需要不同工具。** Lumiton·Omax 提供三种模式，因为研究很少只适合单一方式。
