## 一、为什么选这个方向（从 150 份源库中挖掘）

对源库按主题盘点后，候选方向与选择理由：

| 候选方向 | 源数量 | 排除/入选理由 |

**核心价值**：大温差井是客户真实场景——底部 164℃ 需长效缓凝、顶部 70℃ 需 24h 早强，两者天然矛盾。缓凝剂 26 份源形成完整研发路线时间线（新单体 → QS-20S 搭配 → 咪唑/1.6SG → 大温差 HX-36LB），其中「顶部强度滞后」「温度倒挂」「降黏跷跷板」正是科研 Agent 最能发挥诊断能力的复杂证据问题。

## 二、科研 Agent 与快速聊天的区别（培训讲点）

| 维度 | 快速聊天（Quick Chat） | 科研 Agent（Research Agent） |
|------|------------------------|------------------------------|
| 上下文 | 用户手动选来源、定模式 | **Agent 自主检索**（list → 向量搜索 → 分块读取 → 再检索） |
| 提问方式 | 逐步递进式标准提问 | **一个复杂研究问题**，Agent 自主规划检索路径 |
| 能力 | 基于选定上下文回答 | 5 个私有工具 + 联网搜索 + 科学数据库 + **10 个策研技能自动加载** |
| 可观测 | 回答 + 建议问题 | 思考过程 + 工具调用轨迹 + 历史压缩 + 回答 |
| 适用 | 已知证据、精读分析 | **证据脉络不明、跨文档诊断、复杂综合** |

**10 个策研技能**（Agent 按问题自动选择加载）：chemical-identity-properties、competing-hypotheses、doe-statistical-plan、evidence-critical-appraisal、formulation-compatibility-matrix、hthp-brine-validation、literature-doi-verification、oilwell-cement-additive-diagnosis、scale-up-validation-gates、structured-research-report。

## 三、示范案例设计

### 演示笔记本

「科研Agent示范_大温差缓凝剂顶部强度」：10 份源（全部 embedded+KG），覆盖 2025.6 → 2026.8 缓凝剂时间线：

- 2025.6-9：新单体方向（顶部强度发展、QS-20S 搭配 ×4）
- 2025.10-12：1.6SG 体系、咪唑倒挂、咪唑降黏
- 2026.7-8：大温差缓凝剂 HX-36LB 搭配高温降失水剂（最新 2 份）

### 两轮递进提问（示范「把问题交给 Agent」）

**第 1 轮（诊断大问题）**：

> 大温差缓凝剂是本项目的核心产品。请自主检索并阅读本笔记本内的证据，完成三项任务：
> 1) 按时间线总结各研发路线的关键发现与遗留问题；
> 2) 重点识别「顶部强度发展」与「高温缓凝」之间的矛盾证据；
> 3) 对关键结论区分「证据」与「推断」，并明确列出证据缺口。

**第 2 轮（机理 + 验证）**：

> 基于上一轮梳理，提出 2-3 个解释顶部强度发展不足的机理假设，并为最优先假设给出最小验证实验方案（≤6 组、含对照组、通过标准、失败判据）。

## 四、真实执行结果（有日志佐证）

### Agent 的自主工作轨迹（logs/api.log，trace `ae558bafaef1`）

```
6 轮 agent 迭代，每轮 2-4 次工具调用（共 10+ 次）
→ 列源清单 → 逐份读取 10 份报告 → 历史压缩（17k tokens）
→ 自主纠错：「我先前使用的ID是猜测的，不在范围内。改用工具返回的真实ID列表。」
```

这正是科研 Agent 的示范价值：**用户只问一个问题，Agent 自主完成检索-阅读-再检索循环**。

### 第 1 轮产出（170s，8213 字）

- **完整时间线表**：9 个时间节点 × 关键发现 × 遗留问题，逐条带来源 ID
- **四类矛盾证据**：
  1. 强缓凝直接导致顶部强度滞后（ATMP 90℃ 4 天未初凝；2026.8 六组配方 90℃/24h 全部 1.54-2.76 MPa，无一达 >3.5 MPa 目标）
  2. 温度「倒挂」：升温 5℃ 稠化时间反而翻倍（120℃ 367min → 125℃ 517min），定位到单体 AM
  3. 「降黏」与缓凝时长的跷跷板（还原剂 0.15%→0.25%：黏度 1231→191 mPa·s，稠化 449→307min）
  4. 渤星标杆反衬：QS-20S 存在时 40℃ 强度 6.74→21.86 MPa（去 QS-20S）
- **证据分层**：原始证据（`[source:...]`）vs 转述/派生证据（`[source_insight:...]` 标注"待核对"）

### 第 2 轮产出（248s，7481 字）

- **三个机理假设**：
  - H1（优先）：缓凝剂在 90℃ 低温段的「过度抑制」——强吸附/螯合基团拖长顶部水化诱导期
  - H2：降温路径诱发的吸附迟滞/构象变化（与高温倒挂同源）
  - H3：降黏/分散组分的低温分散效应与竞争吸附
- **H1 六组验证方案**：空白基线 → 渤星标杆 → 缺陷复现 → 剂量减半 → 成核封锁探针（晶种/DMAA）→ 机制定量（吸附量/量热/Ca²⁺），每组含通过标准与失败判据，并给出「组4/5 失败 → 转 H2/H3」的判定逻辑
- **元发现**：指出"现有数据几乎全部为单次实验，是已知证据缺口"，要求每组 ≥2 次平行

## 六、现场演示脚本（约 15 分钟）

### 方案 A：成品讲解（推荐开场）

1. 登录 → 打开笔记本，进入聊天页切到「科研」模式
2. 展示 2 份笔记：第 1 份讲「一个复杂问题换来自动检索的综合报告」，第 2 份讲「假设 + 6 组验证方案」
3. 重点停留：时间线表（证据脉络）、四类矛盾证据（诊断价值）、H1 验证方案的判定逻辑

### 方案 B：实时演示（挑一轮）

1. 研究模式提问框粘贴第 1 轮提问词
2. 展示：思考过程流式 → 工具调用阶段状态 → 综合回答（约 3-4 分钟）
3. 回答后展示引用跳转 + 保存为笔记

### 讲点（与快速聊天对比）

- 「上次我们手动选来源、一步步提问；今天把问题交给科研 Agent，它自己决定先看什么、读哪些段落、什么时候停下来综合。」
- 「注意它中途自己纠正了错误的来源 ID——这是工具驱动 Agent 的正常行为，也说明过程可观测、可审计。」
- 「10 个研究方法技能（如油井水泥外加剂诊断、竞争假设、证据批判性评估）会按问题自动加载，决定报告的结构与严谨性。」

### 风险预案

- 模型不可用：直接用 2 份已保存笔记讲解（成品都在）
- 现场提问超时：预演已证明两轮分别 170s/248s，可提前告知观众"Agent 在阅读 10 份报告，需要 3-4 分钟"
- 回答质量波动：讲解以预生成笔记为准，实时演示仅作过程展示
