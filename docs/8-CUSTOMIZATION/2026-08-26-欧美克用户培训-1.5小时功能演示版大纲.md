## 一、培训定位与演示原则

1. **不是方法论课**：上一版「7 阶段研发闭环」培训解决「怎么用得好」；本次解决「系统还藏了什么你没用到的功能」。
2. **重点讲 6 月以来新增的功能**：试用反馈显示，多数人只用过「上传 + 问答」，导览卡片、来源筛选、科研 Agent、脱敏等新能力基本没被使用。
3. **成品 + 实时结合**：每个环节先展示已产出的成品（降低现场风险），再挑 1-2 个关键操作实时演示。
4. **如实讲边界**：路线图上的待办（实验索引、时间线、产品图谱）明确说明，不夸大。

## 三、逐环节演示脚本

### 1. 开场：新功能地图（5 分钟）

**讲点**：「系统从 6 月到现在新增了 30+ 项能力，今天按你的使用顺序——从登录、传资料、聊天、研究、到数据安全——逐个演示，全程 90 分钟，每个环节你都可以当场上手。」

展示一页总览图（推荐现场直接打开系统对照，不用 PPT）：

```
账号层   个人资料 · 只看我的 · 最近笔记本
来源层   搜索分页 · 来源筛选(本次引用范围) · 仅已嵌入可选 · 数量上限
         解析结果下载(Markdown/ZIP) · 独立图片源(Vision 描述) · 删源三规则
聊天层   导览卡片 · 回答后3条建议 · 阶段等待状态 · 超时气泡 · 保存笔记
研究层   ⭐科研Agent(自主检索+10个策研技能) · ⭐全局提问与搜索(覆盖统计+历史)
组织层   聚合笔记本 · 密码全生命周期
安全层   ⭐出网脱敏透明网关
```

### 2. 账号与工作台（5 分钟）

| 演示 | 操作路径 | 讲点 |
|------|----------|------|
| 🆕 个人资料页 | 侧边栏用户名 → `/profile` | 改显示名称、改密码（旧密码验证），无需找管理员 |
| 🆕 只看我的 | 笔记本页 →「只看我的」开关 | 多人共用时一键只看自己创建的笔记本，可叠加名称搜索 |
| 🆕 最近笔记本 | 侧边栏「笔记本」下 | 最近打开的快进入口，长标题 hover 看全名 |
| 词元统计 | 聊天输入框旁 | 中文界面 Token 已统一为「词元」 |

### 3. 来源管理新能力（13 分钟）—— 使用人员重点

| # | 演示 | 操作路径 | 讲点 |
|---|------|----------|------|
| 3.1 | 🆕 搜索与分页 | Sources 全局页 | 标题回车搜索 + 「第 X/Y 页，共 Z 条」；搜索无结果有明确提示 |
| 3.2 | 🆕 来源筛选=本次引用范围 ⭐核心 | 打开笔记本 → 来源栏筛选框 → 全选/取消全选 | 「资料属于项目」和「这次回答引用哪些」是两件事；取消勾选只是不参与本次回答，来源仍在笔记本 |
| 3.3 | 🆕 仅已嵌入可选 | 添加现有来源弹窗 | 未处理完的来源不出现在候选列表，不再误选「半成品」 |
| 3.4 | 🆕 解析结果下载 | 来源详情页 → 下载菜单 | Markdown 单文件 / ZIP 包（含图片，路径已改写），解析结果可交付、可归档 |
| 3.5 | 🆕 独立图片源 | 上传图片 → 详情页 | 先显示原图再显示 AI 描述；TIFF 自动转 PNG 预览；描述纳入搜索（按图片内容搜） |
| 3.6 | 🆕 删源三规则 | 来源卡片删除/移除 | 自己的+未被引用→直接删；别人的→只能移除；多笔记本引用→需管理员密码 |

**现场演示**：3.2（筛选+全选，30 秒）+ 3.4（下载 ZIP，30 秒）+ 3.5（打开一个图片源，30 秒）。

### 4. 聊天新体验（13 分钟）—— 使用人员重点

**素材**：演示笔记本「培训演示_HX-16L降失水剂证据闭环」（6 源 + 7 份笔记，均已备好）

| # | 演示 | 操作路径 | 讲点 |
|---|------|----------|------|
| 4.1 | 🆕 导览卡片 | 打开笔记本聊天页 | 首次导入后自动生成：摘要 + 关键要点 + 3 条建议问题，点击即发，不知道问什么时从这开始 |
| 4.2 | 🆕 回答后 3 条建议 | 任一回答下方 | 结合本轮问题+回答+上下文生成；点击直接追问；主回答完成即恢复输入框，建议异步生成不阻塞 |
| 4.3 | 🆕 阶段等待状态 | 发问后观察 | 「获取上下文→联网搜索→等待模型（N 秒）→模型输出中→生成建议」，慢的时候能判断是「工作中」还是「卡死」 |
| 4.4 | 🆕 超时气泡 | （讲解，不现场触发） | 超时不再弹一闪而过的英文 toast，而是 AI 气泡 + 中文操作指引（缩小来源范围/新建会话） |
| 4.5 | 保存为笔记 | 回答下方按钮 | 每轮有价值回答一键沉淀，已在演示笔记本里存了 7 份示范 |
| 4.6 | 🆕 联网搜索 | Chat 开关 | Tavily 超时降级；「搜索次数用完」≠模型配额，是 Tavily 单回答上限/月度配额 |

**现场演示**：4.1（展示已生成的导览卡片）+ 4.2（展示 7 份笔记里带建议问题的回答）+ 实时发一个短问题展示 4.3 状态流转（约 1 分钟）。

### 5. ⭐科研 Agent（20 分钟）—— 全场核心

**素材**：演示笔记本「科研Agent示范_大温差缓凝剂顶部强度」（10 源 + 2 份 Agent 报告 + 研究会话）

**讲点结构**：

1. **什么是科研 Agent（3'）**：聊天页切「科研」模式。区别：快速聊天=你选来源、你一步步问；科研 Agent=**你只问一个复杂问题，它自主决定检索什么、读哪些段落、何时停下来综合**。
2. **能力清单（3'）**：5 个内置工具（列源/向量检索/分段读取/读笔记/跨笔记本发现）+ 联网搜索 + 科学数据库连接器 + **10 个策研技能**（自动按问题加载：油井水泥外加剂诊断、竞争假设、证据批判评估、DOE 统计计划、配方兼容矩阵、HPHT 盐水验证、放大验证 Gate、结构化研究报告等）。
3. **现场展示成品（8'）**：打开笔记本展示两份已产出的报告——
   - 第 1 份：一个复杂问题 → Agent 自主 6 轮迭代、10+ 次工具调用 → 完整时间线 + 四类矛盾证据 + 证据/推断分层；
   - 第 2 份：3 个机理假设 + 6 组验证方案（含对照组、通过标准、失败判据）。
   - 亮点讲点：Agent 中途**自主纠错**（发现用了猜测的来源 ID 后改用工具返回的真实 ID）——过程可观测、可审计。
4. **实时演示（5'）**：研究模式发一个短问题（如「本笔记本中最关键的证据缺口是什么？」），展示思考流式 + 工具状态 + 回答。⚠️ 预计 2-4 分钟，若现场网络/模型不稳，直接用成品讲解，实时演示改放录屏。
5. **适用场景（1'）**：证据脉络不明、跨文档诊断、复杂综合问题——用科研 Agent；已知来源的精读问答——用快速聊天。

### 6. ⭐全局「提问与搜索」（10 分钟）

**背景讲点**：这个页面 8 月前一直报「模型供应商返回错误」（实为内部并行检索合并问题，与供应商无关），8-05 已修复——所以多数人可能从没用成功过，现在可以放心用。

| 演示 | 操作路径 | 讲点 |
|------|----------|------|
| 覆盖统计 | 提问后回答上方 | 「来源总数 / 可检索来源 / 本次命中来源」——一眼判断回答覆盖了多少资料；命中少=该补资料或换问法 |
| 历史记录 | 页面内历史面板 | 浏览器保存最近问答+覆盖统计，刷新不丢，验收回溯方便 |
| 流式过程 | 提问后 | 思考过程与最终答案分开渲染；可中途停止且保留已生成内容 |
| 名称统一 | 菜单 | 「询问与搜索」已统一为「提问与搜索」 |

**现场演示**：发一个全局问题（素材：问一个降失水剂类问题，约 30-60 秒），展示覆盖统计 + 历史。

### 7. 笔记本组织（8 分钟）—— 领导关注

| 演示 | 操作路径 | 讲点 |
|------|----------|------|
| 🆕 聚合笔记本 | 新建 → 聚合 | 多个子笔记本合并成一个视图，不拷贝数据、毫秒级同步；试点体系=1 聚合 + 6 子笔记本（产品说明/研发报告/实验记录/现场反馈/水泥批次/外部文献） |
| 🆕 密码全生命周期 | 笔记本卡片「...」→ 密码 | 设密码/改密码/撤销密码，仅创建者可管理；管理员密码可绕过 |
| 🆕 来源数量上限 | 设置 → 文件管理 | 默认 50，可调 1-200，防止单笔记本资料无限堆积 |
| 创建者权限 | 三点菜单可见性 | 管理操作仅创建者可见，防误删误改 |

### 8. ⭐数据安全：出网脱敏（5 分钟）—— 领导关注

**原理（2'）**：出网脱敏透明网关——**库内原文不动**，只在内容发往外部 AI 模型瞬间临时替换（公司名→某企业、井号→实验井A、产品代号→减阻剂A、电话→888888），返回后自动还原。您看到的界面与原来一致，检索、引用、存储全部用原文。

**3 个注意点（2'）**：
1. AI 回答里的电话显示 888888（规则固化不可还原）——查真实电话看原始资料；
2. 联网搜索用科学主题词（如「高温下降失水剂性能」），不用人名井号（代号出网搜不到）；
3. 新人名需管理员在「设置→内容脱敏」录入词典（井号/电话/产品代号自动识别）。

**边界如实说明（1'）**：图片、音频不经过文本脱敏；嵌入向量与库内存储按信任边界决策不脱敏。

### 9. 收尾（11 分钟）

1. **帮助中心（2'）**：`/help` 全中文操作手册，与功能同步更新（8 月已全面同步 §17-§29 新功能），会后把链接发给大家。
2. **路线图如实说明（3'）**：规划中——模型故障自动切换、实验数据索引（Excel 逐条结构化）、实验时间线、产品图谱与版本迭代图、数据备份恢复流程文档化。
3. **两个演示笔记本留给使用人员练习（2'）**：HX-16L 证据闭环（快速聊天 7 阶段示范）、大温差缓凝剂（科研 Agent 示范），会上账号可登录复现。
4. **答疑（4'）**。
